# nemetonplateforme

Poste de pilotage de la plateforme Néméton. Ce dépôt ne contient aucun code produit :
la documentation de la plateforme, ses ADR et le pilotage commun à ses projets. Le code
vit dans les dépôts des projets. Il est conduit par une équipe d'agents IA selon la
méthode de l'Impératrice (plugin `imperatrice`), Pascal gardant la décision.

Où regarder, dans l'ordre :

- Les règles et les sources de vérité : [`CLAUDE.md`](CLAUDE.md).
- Ce qu'on construit et pour qui : [`docs/brief.md`](docs/brief.md), puis [`docs/spec.md`](docs/spec.md).
- Qui dépend de qui : [`docs/carte.yaml`](docs/carte.yaml) (source unique), expliquée dans [`docs/carte-dependances.md`](docs/carte-dependances.md).
- Les décisions d'architecture : [`docs/adr/`](docs/adr/).
- Où en est le travail, et ce qui attend : [`pilotage/kanban.md`](pilotage/kanban.md) (colonnes « Bac à sable » et « Validé »).
- Ce qui s'est passé et pourquoi : [`pilotage/journal.md`](pilotage/journal.md), en ajout seul, les dernières lignes en bas.
- L'équipe, le plafond de PR, les missions : [`pilotage/equipe.md`](pilotage/equipe.md) et `pilotage/missions/`.
- L'état lu de chaque projet au dernier cycle : [`pilotage/etat-cycle.yaml`](pilotage/etat-cycle.yaml).

Un lien plutôt qu'une copie : ce fichier ne recopie aucun état.
